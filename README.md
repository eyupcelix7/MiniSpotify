# 🟢 MiniSpotify

**MiniSpotify** Küçük bir Spotify kontrol paneli. Çalan şarkıyı gösterir, oynat/duraklat, ileri/geri kontrol ve şarkıyı beğenmenizi sağlar (Spotify API).

![.NET Version](https://img.shields.io/badge/.NET-8.0-blue)

## 🚀 Kullanılan Teknolojiler
- **🌊 .NET 10** - Modern Framework
- **🌍 .NET Windows Forms** - Windows uygulaması
- **🌩️ Win32 API** - Çerçeve ayarlamaları için Windows API'si
- **🌠 DWM API** - Medya Kontrolleri için Windows API'si

## ✨ Öne Çıkan Özellikler
- 🎧 Anlık parça bilgisi
- 🖼️ Albüm kapağı
- ⏯️ Mini kontrol paneli
- ❤️ Beğenme (Spotify Beğenilenlere ekler)
